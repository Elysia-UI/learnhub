# Vue 3 项目实践清单

LearnHub 社区整理

## 开发前

- [ ] 明确项目要解决的问题和验收标准。
- [ ] 确认 Node.js 版本与包管理器。
- [ ] 建立 Git 忽略规则，不提交密钥和运行数据。
- [ ] 定义页面、路由、数据模型与组件边界。

## 组件与状态

- [ ] 组件接收明确的 props，通过事件表达变更。
- [ ] 使用 computed 表达派生值。
- [ ] 将需要共享的业务状态放入统一存储。
- [ ] 在卸载时清理监听器、定时器与图表实例。
- [ ] 列表使用稳定、唯一的 key。

## 用户体验

- [ ] 表单同时处理错误、提交中与成功状态。
- [ ] 为列表提供空结果提示和分页。
- [ ] 删除操作先解释影响并确认。
- [ ] 弹窗可以关闭，长内容可以滚动。
- [ ] 无障碍名称清楚，键盘焦点可见。
- [ ] 尊重 prefers-reduced-motion。

## 数据与安全

- [ ] 服务端验证权限，不能依靠隐藏按钮。
- [ ] 展示富文本前做清理，避免 XSS。
- [ ] 上传验证类型、大小与文件内容。
- [ ] 前端不包含私密 API 密钥。
- [ ] 不把 localStorage 当作安全身份认证。

## 发布前

- [ ] 类型检查和生产构建成功。
- [ ] 核心流程经过验证。
- [ ] 手机端无主要内容横向溢出。
- [ ] 刷新详情页可以打开。
- [ ] 文档说明实现范围与已知限制。
