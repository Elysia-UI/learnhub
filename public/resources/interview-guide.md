# 前端面试复习提纲 2026

LearnHub 社区整理 · 用问题检验理解

## JavaScript

1. 基本类型与引用类型有什么区别？
2. 闭包在什么场景下有用？什么时候需要注意内存占用？
3. 解释事件循环、微任务与宏任务。
4. Promise、async/await 如何处理失败？
5. 防抖和节流分别适合什么场景？

## HTML 与 CSS

1. 语义化标签如何帮助无障碍与维护？
2. Flex 与 Grid 的适用场景有什么不同？
3. 什么情况下会发生水平溢出？如何定位？
4. 如何为暗色主题设计颜色变量？

## 浏览器与网络

1. 解释浏览器缓存的基本工作流程。
2. CORS 解决什么问题？
3. XSS 和 CSRF 有什么区别？
4. Cookie、localStorage 与服务端会话的边界是什么？

## 框架与工程

1. 为什么需要组件拆分？如何避免过度拆分？
2. computed 与 watch 如何选择？
3. 路由懒加载有什么作用？
4. 一个失败请求如何反馈给用户？
5. 如何验证一个前端功能真的可用？

## 项目表达练习

按「问题—选择—实现—验证—局限」介绍一个项目。

不要只列技术栈。说明一个具体场景、一个困难、你的判断和实际结果。尚未实现的能力要坦诚说明。
