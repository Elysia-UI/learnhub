# 计算机基础知识图谱

LearnHub 社区整理 · 学习提纲

## 1. 计算机网络

- 网络分层：物理层、数据链路层、网络层、传输层、应用层。
- TCP 与 UDP：连接、可靠性、顺序与使用场景。
- HTTP：请求方法、状态码、缓存与内容协商。
- HTTPS：TLS 握手、证书与加密传输的基本作用。
- DNS：域名解析、缓存与排查过程。

自测：从输入网址到页面出现，浏览器经过了哪些步骤？

## 2. 操作系统

- 进程与线程：资源边界、调度和通信。
- 并发与同步：锁、信号量、竞态条件。
- 内存管理：虚拟内存、页表与缺页。
- 文件系统：目录、权限与持久化。

自测：为什么多线程程序可能出现不同的运行结果？

## 3. 数据结构与算法

- 数组与链表：访问、插入、删除的成本。
- 栈与队列：调用栈、任务队列、广度优先搜索。
- 哈希表：哈希函数、冲突与负载因子。
- 树与图：遍历、搜索与关系建模。
- 复杂度：用输入规模估算时间和空间。

自测：为一个需要频繁按 ID 查询的列表选择合适的数据结构。

## 4. 数据库

- 数据建模：实体、关系、主键与约束。
- 索引：查询效率与写入成本。
- 事务：原子性、一致性、隔离性与持久性。
- SQL：参数化查询、连接与分页。

自测：如何防止同一用户对同一帖子重复点赞？

## 5. 建议的实践顺序

1. 用自己的话解释概念。
2. 写一个小实验验证理解。
3. 记录出现的问题和解决过程。
4. 每周通过主动回忆复习，而不只是反复阅读。
