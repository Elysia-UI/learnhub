## 业务规则

- 普通用户、教师发布和修改帖子进入 `pending`。管理员可通过或填写原因驳回；作者可修改后重新提交。通过前不允许公开读取、评论、点赞和收藏。首次通过审核发放发帖积分，重复审核不重复奖励。
- 分类可以改名、修改描述、停用和恢复。停用保留已有内容，阻止新增内容；没有关联内容的分类才能删除。
- 公告支持草稿、编辑、发布、置顶、撤回公开和删除。草稿仅管理员可读取。
- 全站搜索在 MySQL 查询帖子、问题、课程、资源和用户，先统计、排序、分页，再生成当前页 DTO。不会依赖 bootstrap 的数量上限。课程、问答、资源、排行榜、通知和后台列表也使用独立分页。
- 当前登录身份直接来自服务端会话；公共用户列表不足 500 人或超出其范围都不会影响识别。分页 DTO 携带作者信息。
- 积分流水使用唯一事件键。签到、审核奖励、采纳和悬赏均在事务内执行。发帖、提问、回答和评论支持 `Idempotency-Key`；浏览器网络失败后重试同一内容复用该键。
- 徽章持久化在 `user_badges`。累计签到 7 天、公开帖子 3 篇、一个最佳答案、一份通过审核资源、完成一门课程分别解锁徽章。领取不另外发放积分。`db:init` 和独立补录脚本会为既有用户补齐符合条件的徽章。
- 课程评价要求报名，教师不能评价自己的课程。每人每课一条，可更新或删除；评分根据真实评价重新汇总。旧演示评分因无评价依据已清零。
- 悬赏创建时从可用积分扣除并冻结，不允许发布后改金额。提问者采纳他人答案时，基础采纳积分与悬赏一次结算给回答者。未结算问题删除时退回悬赏；已结算不会重复退款。普通用户不能删除已有回答的问题。旧的未扣款演示悬赏已清零。
- 资源作者可修改资料并重新提交审核；管理员可修改资源。下载仍要求登录和审核通过，记录真实下载及次数，个人中心提供下载历史。
- 个人帖子、评论、问题、回答、资源、收藏、课程、积分、浏览和下载分别分页。数据导出仅查询当前用户勾选的范围，包含全部符合范围记录，不受已加载页面限制。

## AI

服务端使用兼容 OpenAI Chat Completions 的 SSE 协议，参见 [官方接口说明](https://developers.openai.com/api/reference/chat-completions/overview) 和 [流式响应说明](https://developers.openai.com/api/docs/guides/streaming-responses)。模型地址和密钥只从服务端环境读取。

```dotenv
AI_BASE_URL=https://your-provider.example/v1
AI_API_KEY=configure-on-server-only
AI_MODEL=your-provider-model-id
```

配置 `.env` 后重启。基础地址需 HTTPS，开发测试仅允许 localhost 使用 HTTP。不得用 `VITE_` 环境变量传递密钥。

已实现对话创建、当前用户历史分页、连续上下文、流式输出、停止、失败重试和删除。消息保存在 `ai_messages`，按数据库序号排序；重试复用请求键，不追加重复用户消息。每个用户每分钟 10 次、滚动 24 小时 100 次；失败重试也计入额度，删除对话不会重置额度。同一对话同时只能生成一条回答。每次最多携带最近 20 条且合计不超过 32000 字符的上下文，输出上限 2048 token，120 秒超时。

2026-10-28 本机已接入阶跃星辰 Step Plan 的 `step-5-preview`，通过浏览器验证两轮真实回答、连续上下文和刷新后恢复历史。此前的本地协议测试覆盖重试、停止及归属校验。详细证据见 [阶跃星辰接入记录](ai-stepfun-verification.md)。未配置环境仍显示明确提示并允许保存草稿。
