# 需求与完成范围

项目：《教育培训论坛的设计与实现》；产品名：LearnHub · 知学社区。

最新需求已从“前端先行”进入真实后端和云数据库阶段，保留现有 UI，重点验收身份权限和持久化闭环。

| 需求       | 当前实现                                                             |
| ---------- | -------------------------------------------------------------------- |
| 专用数据库 | 腾讯云 MySQL 8，独立 learnhub 库与 learnhub_app 账号                 |
| 用户       | 邮箱注册登录、退出、资料、密码哈希与会话                             |
| 角色       | student / teacher / admin，服务端检查                                |
| 论坛       | 分类、SQL 搜索分页排序、详情、自己的帖子编辑删除、评论回复、点赞收藏 |
| 课程       | 教师建课编辑、图文章节、报名与学习进度                               |
| 资源       | 50 份实际文件、上传、审核、受保护下载                                |
| 问答       | 提问回答、评论、收藏点赞、唯一采纳与奖励                             |
| 成长       | 签到、积分明细、通知、历史                                           |
| 管理       | 用户状态角色、帖子、课程、资源、问答、分类、公告、积分与审计         |
| AI         | 私有学习草稿持久化，模型未接入                                       |
| 界面       | 原有页面、深浅主题、手机导航和响应式布局保留                         |
| 验收       | 单元测试、云数据库接口测试、浏览器发布评论和重启读取                 |

初始目标 30 用户、100 帖、300 评论、20 课程、80 章节、50 资源、30 问题已实际初始化。首页统计通过数据库汇总，未使用参考图中的运营数字。

课程是图文演示学习示例，评分等部分展示元数据为演示内容。视频点播、支付、商业课程授权、邮箱验证/密码找回、真实 AI 流式回答及完整生产运维未完成，不列入已通过验收。
