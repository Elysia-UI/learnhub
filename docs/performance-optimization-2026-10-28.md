# 低带宽访问优化

日期：2026-10-28。目标为原服务器的 3Mbps 公网带宽，优化现有页面传输，不改变数据库中的图片地址或业务记录。

## 已实施

- 保留 50 张原始公共图片，增加 WebP 网页副本，按已知路径精确映射；上传文件、外部 URL 和私有资源下载不经过前端映射。
- 公共图片原始合计 9,856,231 字节，选用的桌面副本合计 1,658,096 字节，减少 83.2%。该数字是整个公共图片集合，不代表每次首页都会下载全部图片。
- 欢迎横幅从 2,596,988 字节改用 219,756 字节（1920×640）；手机使用 72,010 字节（960×320）。画面与构图沿用原图，只做尺寸和编码压缩，原文件仍保留。
- 课程、帖子配图和公共头像使用压缩副本；头像延迟加载，图片异步解码。
- 原有公开上传头像按浏览器 Accept 协商返回 320px WebP 缓存副本，原文件、原 URL 和数据库记录保留；不改资源附件下载。实际既有头像从 1,233,101 字节降为 3,876 字节，减少 99.7%，条件请求返回 304。转换最多 2 个并发、16 个排队；动画、超大像素、小图、解码失败及无收益情况保留原图。缓存目录没有独立公开路由。
- 轮播首张高优先级，首张完成后才开始计时；6 秒后按需读取下一张，成功解码再切换，避免首屏同时抢带宽和慢网空白。保留自动播放、悬停暂停和减少动态效果设置。
- 去除样式中的 Google Fonts 在线导入，沿用本地字体栈，避免首次渲染依赖外部字体服务。
- 生产模式的带哈希构建文件长期缓存，公共图片缓存一天，HTML 保持重验证；业务及私聊接口不纳入公共静态缓存。
- 提供 Nginx 文本 gzip 配置；好友 SSE 和 AI 增量输出禁用压缩及缓冲。该配置尚未在云服务器执行。

## 本机模拟记录

浏览器使用正式构建、匿名只读接口、1440×960 视口、60ms 模拟延迟、下载上限 375,000 字节/秒（3Mbps）、禁用缓存。两组均模拟减少动态效果以停留在首张横幅。优化前使用本次改动前保留的构建，优化后使用本轮构建；两组共用当前本机后端及云数据库，没有模拟业务数据，没有启用 Nginx gzip。

单次样本中，**从开始导航到首张横幅响应结束**：优化前 23,865.9ms，静态图片优化后 4,244.1ms。它包含页面脚本、数据库接口和其他并行图片的等待，不能等同于单张图片理想下载时间、页面白屏时间、完整页面加载时间或正式公网性能承诺。实际用户数量、机器人流量、缓存、数据库延迟和代理配置都会影响结果。

375×850 手机视口实际选中 `hero-960.webp`（72,010 字节），从导航到横幅响应结束 3,058.3ms。页面有纵向滚动条时内容宽 360px，文档和内容宽度相同，没有横向溢出。优化后没有外部字体请求。

## 维护

```powershell
npm ci
npm run images:optimize  # 更新公共原图后重新执行；只写压缩副本及映射
npm run test:unit
npm run test:assets
npm run build
npm start
```

压缩脚本固定使用锁文件中的 sharp；不在每次页面请求中转换公共图片。提交原图、压缩副本和 `src/data/optimized-images.json`，其他机器直接构建即可。不要只上传源代码遗漏 `public/images/optimized`，也不要把私有文件目录作为静态站点目录。

正式部署按 [部署说明](deployment.md) 配置缓存、HTTPS、数据库加密连接和文本压缩。本轮没有修改云服务器或购买带宽。

## 验证结果

- `npm run test:unit`：37/37 通过，包含首图加载、按需轮播、悬停竞态、错误清理、减少动态效果、图片文件完整性及私有 URL 不被映射。
- `npm run test:assets`：15/15 通过，覆盖真实图片解码、缓存与 304、同文件去重、并发上限、动画和解码失败回退、私有文件边界、HTML 与静态文件缓存隔离。
- `node --test --test-concurrency=1 --test-name-pattern="资源上传校验" server/tests/api.test.mjs`：真实 HTTP + 云数据库相关资源流程 1/1 通过。仅运行本次相关场景，没有重复完整项目审计。测试创建的用户与资源由测试清理，并退出额外管理员会话。
- `npm run build`：TypeScript 与 Vite 生产构建通过，Vite 6.55 秒。
- 实际后端验证了公开头像原编码、WebP 编码、正确 Content-Type、Vary、缓存和 304，无数据库写入。
- 重启本地前后端后，正常首页浏览器实际收到头像 `image/webp`、正文 3,876 字节；可见图片没有损坏，控制台未捕获错误或警告，桌面及正常窗口没有横向溢出。已有浏览器可能继续复用旧头像缓存，缓存有效时不会重复下载旧图。
- 开发过程中引用映射文件时曾出现短暂 HMR 缺失文件提示；压缩映射生成并重启本地服务后已恢复。临时旧构建预览的隐藏父目录回退问题已修复并重跑静态测试。
