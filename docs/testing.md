## 接口 13 项

server/tests/api.test.mjs 启动真实 HTTP 服务并连接腾讯云 MySQL，建立随机虚拟账号，测试结束仅清理明确属于本轮的记录和文件。未使用数据库 mock。

1. 注册、scrypt 哈希、重复邮箱、拒绝注册角色注入、错误密码、当前会话及公开字段隐私。
2. 游客写入、普通用户访问管理、缺 CSRF、错误 Origin 的服务端拦截。
3. 发布帖子和评论，SQL 查到记录；独立 HTTP 客户端重新读取。
4. 帖子编辑删除的作者检查，回复的父评论归属。
5. 点赞收藏开关，唯一约束及重复请求幂等。
6. SQL 分页、搜索、排序，以及注入字符串保持参数查询。
7. 五个并发签到只生成一条签到和一笔积分。
8. 问答只有提问者可采纳，重复采纳不能重复奖励。
9. 管理员授予教师后旧会话失效；教师创建课程；报名进度去重和非法章节拒绝。
10. 伪装文件拒绝、真实文本上传、待审不可下载、审核权限、重复审核冲突、下载内容与计数；管理员删除已下载资源、级联记录和文件清理。
11. 管理员停用撤销会话、禁止登录，启用后可重新登录。
12. 错误旧密码拒绝；正确改密撤销全部旧会话；重新登录及退出后禁止写入。
13. 重复初始化不覆盖业务；演示章节规模和 50 份实际非空资源文件。
